# aranaprostudio.com

Sitio web de **APS · AranaProStudio**: *Vision into results.*

```bash
pnpm install
pnpm dev       # http://localhost:4321
pnpm build     # revisa tipos y genera dist/
pnpm iconos    # regenera favicon, íconos y og.png desde los SVG oficiales
```

- Contenido editable: `src/lib/sitio.ts`
- Marca: `docs/MARCA.md`
- Despliegue en Hostinger: `docs/DESPLIEGUE.md`
- Estado del proyecto: `docs/ESTADO.md`
